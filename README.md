# House Price Prediction

Предсказание цены продажи жилья по описанию дома с помощью линейных моделей. Набор данных: Ames Housing (2 930 домов, 80 признаков, целевая переменная `Sale_Price`).

В проекте всё написано в стиле scikit-learn: собственные препроцессоры и модели с интерфейсом `fit` / `predict`, объединённые в `Pipeline` и проверенные кросс-валидацией. Отдельно реализована линейная регрессия с нуля (мини-батч SGD).

## Результаты

Метрика: RMSLE (корень из среднего квадрата ошибки в логарифмах), поскольку для цен важна относительная, а не абсолютная ошибка. CV: 5-fold на обучающей выборке, test: отложенная выборка (20%), использованная один раз.

| Модель | CV RMSLE | test RMSLE | test MAE, $ |
|---|---|---|---|
| Linear Regression, числовые признаки (бейзлайн) | 0.1975 | 0.1950 | 23 823 |
| Ridge на `log(price)`, числовые признаки | 0.1651 | 0.2160 | 26 819 |
| то же + feature engineering | 0.1635 | 0.1707 | 21 539 |
| то же + 4 категориальных признака (one-hot) | 0.1390 | 0.1491 | 17 282 |
| то же + все категориальные признаки | 0.1274 | 0.1358 | 14 888 |
| **Итоговый пайплайн (alpha подобран по CV)** | **0.1246** | **0.1323** | **14 668** |
| SGD с нуля, числовые признаки | – | 0.1937 | 23 870 |

## Главные выводы

- **Логарифм таргета** — самое важное решение для линейной модели: он снижает CV-ошибку и гарантирует положительные предсказания. Без него один очень маленький дом получил отрицательную цену и испортил метрику на всём тесте.
- **Категориальные признаки** дают наибольший прирост: one-hot по всем 46 категориальным колонкам снижает CV RMSLE с 0.164 до 0.127.
- **Одному hold-out разбиению доверять нельзя.** Логарифм таргета улучшает CV по всем фолдам, но на одном тестовом разбиении без дополнительных признаков выглядит хуже. Поэтому решения принимались по кросс-валидации.
- **Выбросы:** два огромных дома, проданных по низкой цене (тип продажи `Partial`), дают заметную часть ошибки. Без них test RMSLE падает с 0.132 до 0.097. Для остальных домов около 95% предсказаний отличаются от факта не более чем на 20%.
- **Самописный SGD** сходится к решению, близкому к аналитическому (корреляция весов с `Ridge` 0.997), что подтверждает корректность градиентов и регуляризации.

## Что внутри

```
.
├── house_price_prediction.ipynb   # анализ данных, препроцессоры, модели, эксперименты
├── requirements.txt
├── .gitignore
└── data/                          # сюда нужно положить данные (в репозиторий не включены)
```

Ключевые классы, реализованные в ноутбуке:

- `BaseDataPreprocessor`, `SmartDataPreprocessor`, `OneHotPreprocessor`: цепочка препроцессоров (стандартизация, замена скрытых пропусков, расстояние до центра, логарифм скошенных признаков, one-hot);
- `ExponentialLinearRegression`: `Ridge`, обученный на логарифме таргета;
- `SGDLinearRegressor`: линейная регрессия с L2-регуляризацией и мини-батч градиентным спуском.

## Как запустить

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Скачайте набор данных Ames Housing в CSV-формате (колонки вида `Gr_Liv_Area`, `Sale_Price`, `Longitude`, `Latitude`) и сохраните как `data/ames_housing.csv`.
3. Откройте и выполните ноутбук:
   ```bash
   jupyter notebook house_price_prediction.ipynb
   ```

Все случайные процессы зафиксированы (`SEED = 24`), поэтому результаты воспроизводятся.

## Что можно улучшить

- убрать выбросы и проверить влияние на метрику;
- закодировать порядковые признаки качества числами вместо one-hot;
- добавить взаимодействия и полиномиальные признаки;
- попробовать `Lasso` / `ElasticNet` для отбора признаков;
- сравнить с градиентным бустингом на тех же признаках.
